## 流程

### 1. 初次输入
同一用户 `usr_kylin_004`：

1. `开发时默认使用 Kylin-IDE 打开工程`（`PREF-0003`）  
2. `用户连续三次要求输出完整代码目录结构`（`PREF-0050`，由原 PREF-0001 克隆到本用户）

### 2. 产生什么记忆
写入本用户长期偏好：

1. `tool.editor = kylin_ide`  
2. `output.structure = complete_tree`  

检索侧可命中**公共知识** `mem_kb_0001`（打开终端），该条不属于其他用户的私有记忆。

### 3. 第二次调用
用户：`帮我在麒麟上打开终端，并按我的习惯给一个工程目录结构说明`。

系统应：

- 解析本用户偏好：Kylin-IDE + 完整目录树  
- 检索：`RET-0051`（查询用户=`usr_kylin_004`）→ gold 公共 `mem_kb_0001`  
- **冲突（方向与金标一致）**：该用户**原先使用 VS Code**，后来改为 **Kylin-IDE** → `CONF-0021`  
  - 旧：`tool.editor=vscode`  
  - 新：`tool.editor=kylin_ide`  
  - 金标：`relation=replace` / `strategy=keep_new`（保留 Kylin-IDE）  
- 临时指令对照：`PREF-0048`（本用户「只要这一次用英文」）→ 不得写成长期偏好

### 4. 预期结果
| 检查点 | 期望 |
|--------|------|
| 偏好 | `kylin_ide` + `complete_tree`，且均属 `usr_kylin_004` |
| 冲突 | 旧 VS Code → 新 Kylin-IDE；`replace`/`keep_new` |
| 检索 | Top-K 含公共 `mem_kb_0001` |
| 回答 | 终端打开方式 + 完整目录结构 + Kylin-IDE |
| 隔离 | 不读取 `usr_kylin_002` 等其他用户私有记忆 |

## 六回合完整剧本（联调 / 演示版）

> 全程固定 `user_id=usr_kylin_004`。公共知识 `mem_kb_0001` 归属 `usr_corpus_shared`，不得当作其他用户私有记忆。  
> 本剧本覆盖：偏好写入 → 隐式偏好 → 检索 → 冲突处理 → 临时指令边界 → 用户隔离。

| 回合 | 目标 | 关联用例 |
|------|------|----------|
| T1 | 显式偏好写入 | `PREF-0003` |
| T2 | 隐式偏好写入 | `PREF-0050` |
| T3 | 检索 + 偏好应用 | `RET-0051` + `mem_kb_0001` |
| T4 | 冲突 replace | `CONF-0021` |
| T5 | 临时指令不误记 | `PREF-0048` |
| T6 | 用户隔离 | 对照 `usr_kylin_002` 私有记忆 |

### T1 — 显式偏好：默认 IDE

**用户输入**
```text
开发时默认使用 Kylin-IDE 打开工程
```

**系统应做**
- 写入长期偏好：`tool.editor = kylin_ide`（`category=tool_choice`，`scope=global`）
- 不触发冲突（尚无旧值）

**验收**
| 检查项 | 期望 |
|--------|------|
| 偏好键值 | `tool.editor=kylin_ide` |
| 用户 | `usr_kylin_004` |
| 临时指令 | `is_ephemeral_instruction=false` |

---

### T2 — 隐式偏好：完整目录结构

**用户输入**（连续三次同类行为，可合并为一条事件摘要）
```text
请给出完整代码目录结构
请再给我完整目录树
第三次仍要求：输出完整代码目录结构
```

**系统应做**
- 从行为推断长期偏好：`output.structure = complete_tree`
- 不得只记单次输出格式

**验收**
| 检查项 | 期望 |
|--------|------|
| 偏好键值 | `output.structure=complete_tree` |
| 推断类型 | 隐式偏好（非直说 key 名） |
| 与 T1 共存 | 两条偏好均属同一用户 |

---

### T3 — 检索 + 个性化回答

**前置状态**
- 用户已有：`tool.editor=kylin_ide`，`output.structure=complete_tree`
- 语料库含公共知识 `mem_kb_0001`（打开终端）

**用户输入**
```text
帮我在麒麟上打开终端，并按我的习惯给一个工程目录结构说明
```

**系统应做**
1. **检索**：查询用户=`usr_kylin_004`，命中公共 `mem_kb_0001`（`RET-0051` gold）
2. **偏好应用**：回答中体现 Kylin-IDE + 完整目录树
3. **回答要点**：`Ctrl+Alt+T` 或开始菜单搜「终端」+ 完整工程目录结构说明

**验收**
| 检查项 | 期望 |
|--------|------|
| 检索 Top-K | 含 `mem_kb_0001` |
| 回答内容 | 终端打开方式 + 完整目录结构 |
| 个性化 | 提及/遵循 Kylin-IDE 习惯 |
| 跨用户泄漏 | 0（不读其他用户私有记忆） |

---

### T4 — 冲突：VS Code → Kylin-IDE

**前置状态**
- 旧记忆：`tool.editor=vscode`（`mem_old_s21`）
- 新输入/新记忆：`tool.editor=kylin_ide`（`mem_new_s21`，来自 T1）

**触发方式**（二选一，联调任选）
- 在 T1 之前先注入旧记忆 `vscode`，再执行 T1；或
- 用户明确说：`我以前用 VS Code，现在改默认 Kylin-IDE`

**系统应做**
- 判定：`relation=replace`，`strategy=keep_new`
- 保留 Kylin-IDE，废弃/降级 VS Code

**验收**
| 检查项 | 期望 |
|--------|------|
| relation | `replace` |
| strategy | `keep_new` |
| 最终有效值 | `tool.editor=kylin_ide` |
| 用户 | 仅 `usr_kylin_004` |

---

### T5 — 临时指令：只要这一次英文

**用户输入**
```text
只要这一次用英文输出，平时还是中文
```

**系统应做**
- 识别为临时指令：`is_ephemeral_instruction=true`
- **不得**写入长期偏好 `output.language=en`
- 本次回答可用英文；会话结束后偏好表不变

**验收**
| 检查项 | 期望 |
|--------|------|
| 长期偏好表 | 无新增 `output.language` |
| 临时标记 | `ephemeral_text=output.language=en`（会话级） |
| T1/T2 偏好 | `kylin_ide`、`complete_tree` 仍在 |

---

### T6 — 用户隔离：同问不同答

**前置状态**
- `usr_kylin_004`：有 T1–T2 偏好 + 可检索 `mem_kb_0001`
- `usr_kylin_002`：另有私有偏好（如 `tool.editor=vscode`），**不得被 004 读到**

**用户输入**（两个用户分别提问，同一句）
```text
按我的习惯，用什么 IDE 开发？
```

**系统应做**
- `usr_kylin_004` → 回答 Kylin-IDE + 完整目录树习惯
- `usr_kylin_002` → 仅返回该用户自己的偏好（如 VS Code）
- 互不串记忆

**验收**
| 检查项 | 期望 |
|--------|------|
| 004 回答 | 含 `kylin_ide`，不含 002 私有字段 |
| 002 回答 | 含 002 自己的 IDE 偏好 |
| 检索隔离 | `cross_user_leak_cases=0` |
