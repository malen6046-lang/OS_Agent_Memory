### 3. 第二次调用（遗忘指令）
用户：`忘记我的输出格式偏好，备份流程留下`（`FORG-0001.instruction`）。

系统流程（V1.2.1）：

1. **preview**：解析范围 → 候选删除列表 + 风险级别 + confirmation_token  
2. 用户确认（本用例 `requires_second_confirm=false` 时可直接带 token execute）  
3. **execute**：逻辑删除（tombstone），向量侧精准删除；**禁止 DropCollection**

### 4. 预期结果
| 检查点 | 期望 |
|--------|------|
| preview 应删 | `["mem_fmt"]` |
| preview 应留 | `["mem_backup","mem_fw"]` |
| execute 后 | `mem_fmt` → `tombstoned`；sqlite/向量对删除目标无残留 |

| 二次问答 | 再问输出格式偏好时不应再召回已删记忆；备份问题仍可引用 `mem_backup` |
