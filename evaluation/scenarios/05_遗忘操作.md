### T1 — 夹具准备：三条活跃记忆

**系统侧注入**（`FORG-0001.memory_fixtures`，均属 `usr_kylin_003`）
- `mem_fmt`：输出格式偏好相关
- `mem_backup`：备份流程相关
- `mem_fw`：防火墙相关

**验收**
| 检查项 | 期望 |
|--------|------|
| 夹具数量 | 3 条 |
| status | 均为 `active` |
| user_id | 均为 `usr_kylin_003` |

---

### T2 — preview：识别删除目标

**用户输入**
```text
忘记我的输出格式偏好，备份流程留下
```

**系统应做**
- 生成 preview：
  - `should_delete_ids = ["mem_fmt"]`
  - `should_keep_ids = ["mem_backup", "mem_fw"]`
- 输出确认令牌（系统派生，非标注硬编码）

**验收**
| 检查项 | 期望 |
|--------|------|
| preview 删除 | 仅 `mem_fmt` |
| preview 保留 | `mem_backup` + `mem_fw` |
| preview P/R | 与 GT 一致 |

---

### T3 — execute：tombstone 执行

**用户确认** preview 后执行遗忘。

**系统应做**
- `mem_fmt` → `status=tombstoned`
- `mem_backup`、`mem_fw` 仍为 `active`
- 向量侧无残留；**禁止 DropCollection**

**验收**
| 检查项 | 期望 |
|--------|------|
| execute 成功 | `mem_fmt` tombstoned |
| 过删 | 0 |
| 欠删 | 0 |
| DropCollection | 禁止 |

---

### T4 — 扩展遗忘：删防火墙、留锁屏

**前置状态**（`FORG-0002` 夹具）
- `mem_fw`：防火墙（应删）
- `mem_lock`：锁屏策略（应留）
- `mem_theme`：主题偏好（应留）

**用户输入**
```text
忘掉防火墙相关记忆，保留锁屏策略
```

**系统应做**
- preview：`delete=["mem_fw"]`，`keep=["mem_lock","mem_theme"]`
- execute：仅 `mem_fw` tombstoned

**验收**
| 检查项 | 期望 |
|--------|------|
| 删除 | 仅防火墙相关 |
| 保留 | 锁屏 + 主题 |
| 与 T3 不冲突 | T3 已删的 `mem_fmt` 不再出现 |

---

### T5 — 安全约束：禁止整库删除

**触发方式**
- 任意遗忘 execute 时检查系统行为
- 或用户说：`清空我所有记忆`（高风险，应 `requires_second_confirm`）

**系统应做**
- **绝不** DropCollection / 整库清空
- 高风险指令需二次确认

**验收**
| 检查项 | 期望 |
|--------|------|
| DropCollection | 未执行 |
| 部分遗忘 | 仅 tombstone 目标条目 |
| 二次确认 | 高风险时触发 |

---

### T6 — 用户隔离：不误删他人记忆

**前置状态**
- `usr_kylin_003`：执行 T1–T4 遗忘
- `usr_kylin_005`：另有私有记忆，**不得被 003 的遗忘指令影响**

**用户输入**（003 用户）
```text
忘记我的输出格式偏好
```

**系统应做**
- 仅操作 `usr_kylin_003` 名下夹具
- `usr_kylin_005` 的记忆完全不受影响

**验收**
| 检查项 | 期望 |
|--------|------|
| 003 遗忘范围 | 仅本用户 |
| 005 记忆 | 无变化 |
| 跨用户误删 | 0 |
