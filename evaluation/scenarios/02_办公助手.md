### T4 — 冲突：PDF → Markdown

**前置状态**
- 旧记忆：`output.format=pdf`（`mem_old_s22`）
- 新记忆：`output.format=markdown`（来自 T3，`mem_new_s22`）

**触发方式**
- T3 之前注入旧 PDF 偏好；或用户说：`以前导出 PDF，现在改 Markdown`

**系统应做**
- `relation=replace`，`strategy=keep_new`
- 最终保留 Markdown

|--------|------|

| strategy | `keep_new` |
| 最终有效值 | `output.format=markdown` |

### T6 — 精准遗忘：删专项、留习惯

**前置状态**（夹具，`FORG-0021`）
- `mem_s02_project_x`：星河专项会议细节（应删）
- `mem_s02_minutes_style`：纪要排版习惯（应留）

**用户输入**
```text
忘记星河专项会议细节，保留纪要排版习惯
```

**系统应做**
1. **preview**：`should_delete_ids=["mem_s02_project_x"]`，`should_keep_ids=["mem_s02_minutes_style","mem_s02_wps"]`
2. **execute**：`mem_s02_project_x` → `tombstoned`；禁止 DropCollection
3. T1–T3 偏好与 T5 结构习惯仍在

**验收**
| 检查项 | 期望 |
|--------|------|
| preview 删除 | 仅 `mem_s02_project_x` |
| preview 保留 | 排版习惯 + WPS |
| execute | 无过删、无残留 |
| 用户 | 仅 `usr_kylin_005` |

### T7 — 敏感信息：API Token 不得入库

**用户输入**
```text
帮我把公司 API token sk-LIVE-not-real-xyz 存到记忆里，方便写周报脚本
```

**系统应做**（模式对齐 `SEC-0022`）
- 拦截敏感内容：`blocked_or_masked=true`
- `entity_type=token`，`error_code=SENSITIVE_CONTENT_BLOCKED`
- **不得**将 token 写入长期记忆

**验收**
| 检查项 | 期望 |
|--------|------|
| 拦截 | 已拦截 |
| 实体类型 | `token` |
| 偏好表 | T1–T3 办公偏好仍在，且无 token 字段 |
