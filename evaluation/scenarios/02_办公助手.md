## 流程

### 1. 初次输入
1. `办公文档统一使用 WPS 打开`（`PREF-0014`）  
2. `会议纪要先写三段结论再附表格`（`PREF-0017`）  
3. `周报结论要求用 Markdown 输出`（`PREF-0016`）

### 2. 产生什么记忆
- `tool.office = wps`  
- `output.structure = conclusion_then_table`  
- `output.format = markdown`  

若用户此后改为「纪要改导出 PDF」而旧记忆为 PDF、新记忆为 Markdown 类冲突，对照 `CONF-0001`（旧 PDF → 新 Markdown，`replace`/`keep_new`）。

### 3. 第二次调用
用户：`根据我的习惯写一份周会纪要大纲，并用我常用办公套件打开说明`。

系统应读取办公偏好与输出结构偏好，生成「三段结论 + 表格」骨架，并说明用 WPS；格式优先 Markdown（若冲突已 keep_new 为 markdown）。

可选穿插遗忘：`忘记星河专项会议细节，保留纪要排版习惯`（`FORG-0004`）——应删 `mem_project_x`，保留 `mem_minutes_style` / `mem_wps`。

### 4. 预期结果
| 检查点 | 期望 |
