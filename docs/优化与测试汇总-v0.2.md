# OS Agent Memory MVP：Kylin REAL 模式优化与验证汇总

## 1. 本轮目标

本轮在不修改算法模型本身的前提下，完成麒麟端真实服务接入、响应耗时透传、Hybrid 检索权重优化，以及检索、性能和遗忘准确率验证。

## 2. 运行架构

```text
Kylin Embedding Runtime
        ↓ Unix Socket
kylin-sdk-sidecar
        ↓ Unix Socket: /tmp/os-agent-kylin-sidecar-<uid>.sock
FastAPI（REAL 模式，127.0.0.1:18001）
        ↓
Orchestrator / Repository / Vector Store
        ↓
SQLite + Kylin Vector Engine
```

## 3. 本轮代码变更

### 服务接入

- `adapters/embedding/kylin_provider.py`：Embedding 服务适配器。
- `adapters/embedding/kylin_sidecar_client.py`：通过 Unix Socket 调用 Sidecar。
- `adapters/vector_store/kylin_vector_store.py`：Kylin Vector Engine 适配器。
- `adapters/evaluation/`：REAL 模式评测服务适配。
- `configs/kylin-real.yaml`：REAL 模式配置。
- `configs/kylin.yaml`：默认麒麟配置调整。

### API 与响应

- `app/dependencies/services.py`：服务容器启动、REAL/MOCK 模式选择和依赖健康检查。
- `app/dependencies/api_service.py`：将 Orchestrator 的后端耗时、provider 和降级信息透传到 HTTP 响应。
- `app/core/responses.py`：统一成功响应处理私有 `__response_meta`，修复 `meta.elapsed_ms` 显示为 0 的问题。
- `app/core/config.py`：运行环境和服务模式配置读取。

### 检索优化

- `modules/knowledge_retrieval/algorithm_v1_1/hybrid_retriever.py`：支持向量与 BM25 加权 RRF。
- 当前候选权重：向量 `0.7`，BM25 `0.3`。
- 权重通过环境变量配置：

```bash
export OS_AGENT_VECTOR_WEIGHT=0.7
export OS_AGENT_BM25_WEIGHT=0.3
```

## 4. REAL 模式启动

### 终端一：启动 Sidecar

```bash
cd ~/os-agent-memory-lab/kylin-sdk-sidecar
rm -f "/tmp/os-agent-kylin-sidecar-$(id -u).sock"
./build/kylin_sdk_sidecar
```

确认 Socket：

```bash
test -S "/tmp/os-agent-kylin-sidecar-$(id -u).sock" && echo "Sidecar Socket 正常"
```

### 终端二：启动 FastAPI

```bash
cd ~/os-agent-memory-lab/OS_Agent_Memory_MVP
source .venv/bin/activate
export OS_AGENT_ENV=kylin-real
export OS_AGENT_SERVICES__MODE=real
export OS_AGENT_VECTOR_WEIGHT=0.7
export OS_AGENT_BM25_WEIGHT=0.3
python -m uvicorn app.main:app --host 127.0.0.1 --port 18001
```

### 终端三：健康检查

```bash
curl -sS http://127.0.0.1:18001/api/v1/health | python -m json.tool
```

健康响应必须包含：

- `success: true`
- `data.mock: false`
- Embedding 状态为 `ok`
- Vector Store 状态为 `ok`
