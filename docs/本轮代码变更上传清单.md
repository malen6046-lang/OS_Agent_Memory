# 本轮代码变更上传清单

## 不要上传

- `.venv/`
- `.pytest_cache/`
- `__pycache__/`
- `*.pyc`
- 临时日志和 `/tmp` 下的测试文件
- 本机生成的构建缓存

## 上传前命令

```bash
git status --short
git diff --check
python -m pytest tests/unit -q
```

## GitHub Desktop 操作

1. 打开仓库 `OS_Agent_Memory_MVP`。
2. 在 Changes 页面核对上述文件。
3. 确认没有 `.venv`、缓存和临时文件。
4. 填写提交说明：`feat: integrate Kylin real services and optimize evaluation`。
5. 点击 Commit，再点击 Push origin。
